# 🥜 Galande Snacks

**Premium E-commerce Landing Page | Est. 1999**

A modern, high-motion e-commerce landing page for Galande Snacks featuring advanced GSAP animations, smooth scrolling, and a beautiful design inspired by Maharashtra's authentic snack culture.

![Galande Snacks Preview](https://via.placeholder.com/800x400?text=Galande+Snacks+Preview)

---

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** (v9 or higher)

### Installation

```bash
# Navigate to the project directory
cd galande-snacks

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at **http://localhost:5173**

---

## 📦 Build for Production

```bash
# Create production build
npm run build

# Preview production build locally
npm run preview
```

## ✨ Features

### Animations
- 🎯 Horizontal scroll product showcase

- 🪄 3D floating product bags
- ✨ Mouse-tracking parallax effects
- 💫 Scroll-triggered reveals

### E-commerce
- 🛒 Full cart functionality
- ➕ Add/remove products
- 📱 Responsive design
